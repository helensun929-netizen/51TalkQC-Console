核心数据

Coach 教练名单

  • coachId · name · wecom业务系统编号、姓名、企微名
  • level · tag教练等级、教练标签
  • team · base · group教练团队、基地、组别
  • joinDate · leaveDate入职、离职日期
  • tags画像：风格、能力、素质、技能、违规

Standard 质检标准

  • version版本号，每次保存 +1
  • pts · red · extra检查点、红线、附加环节
  • courses · rules培训课程、等级与复检规则
  • note · by修改说明、操作人

QcRecord 课堂质检记录

  • std体验课 / 正课
  • date · batch · qcType日期、批次、质检类型
  • coachName · coachId教练
  • lessonType · lessonNo课型、课次（正课）
  • duration · newWords时长、学新词数
  • marks每个检查点：未达成 / 不适用
  • note问题记录
  • result得分、等级、培训、复检截止

Training 培训任务

  • qcId首检记录
  • required · elective必修 / 选修课程
  • due复检截止
  • trainDate · trainer · passed培训与通关
  • recheckQcId · recheckScore复检记录与得分
  • conclusion结案 / 二次培训 / 升级

Case 工单

  • src · qcId来源（含课堂质检）
  • coachName · coachId教练
  • summary · detail问题与证据
  • status · assignee状态、处理人
  • violation · penalty判定结果
  • events时间线
数据存储

在 claude.ai 上打开时，数据存在这个工作台自带的共享数据库里，所有被分享的同事看到同一份、实时同步。权限按分享级别：管理员（Editor）可改质检标准、导入教练名单；质检专员（Contributor）可录入质检、处理工单和培训；主管（Viewer）只看。离线打开 HTML 文件时为本地模式，数据只存在那台电脑的浏览器里。
